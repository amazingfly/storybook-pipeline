# Workflow support index

`workflows.json` is the machine-checked source for this index. Supported means
maintained entry point with CPU checks, not a claim of current GPU availability
or deployment. Archived source stays in place to preserve historical paths.

| Workflow | Status | Requirements |
| --- | --- | --- |
| `storybook-production` | supported | Images checkout/assets, Colab or Q8, Piper, FFmpeg |
| `qwen-review` | supported | Qwen server and completed candidates |
| `curated-assembly` | supported | Reviewed selections, FFmpeg |
| `remote-qwen-review` | experimental | Remote model/runtime |
| `flux-storybook` | experimental | FLUX model and Colab |
| `accessory-v1-v2` | archived | Historical experiments |
| `accessory-v4-v5` | experimental | Specialized recipes |
